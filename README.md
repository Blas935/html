# Flores para ti

Página romántica estática para GitHub Pages. Incluye rosas ilustradas, un sobre animado y una carta que puedes abrir y cerrar. Se adapta a celulares, permite usar el teclado y respeta la preferencia de reducir movimiento. No necesita instalación, dependencias ni servicios externos.

## Cambiar el mensaje

Abre `index.html` y busca `const CARTA`. Cambia `titulo`, los textos dentro de `parrafos` y `firma`. Conserva las comillas y las comas. El contenido se muestra como texto, por lo que no necesitas escribir HTML.

También puedes cambiar el título visible buscando `Flores para ti`, y el texto del jarrón buscando `con todo` y `mi cariño`.

## Publicar en GitHub Pages

Sube `index.html` a la raíz de tu repositorio. En Settings → Pages, elige **Deploy from a branch**, la rama **main** y la carpeta **/ (root)**. Guarda y espera a que termine la publicación. Para el repositorio `Blas935/html`, la dirección es https://blas935.github.io/html/.

Puedes abrir `index.html` directamente en un navegador para ver y probar la página antes de subirla.
